# CSV FAQ Agent

A chat agent that answers questions using **only** the data in CSV files you provide. It is built on LangChain's pandas DataFrame agent and comes with two interfaces:

- **Streamlit web UI** (`streamlit_app.py`): a 3-step wizard.
- **Terminal chat** (`app.py`): the original command-line version.

The agent is told not to assume anything. If a question is ambiguous (several rows or datasets could apply, or a detail such as plan, card type or department is missing), it asks a short clarifying question. If the CSVs don't contain the answer, it says so. Recent conversation turns are sent with each question, so it can understand your reply to a clarifying question.

## Project structure

```
csv-faq-agent/
├── streamlit_app.py     # Streamlit wizard UI
├── app.py               # Terminal entry point
├── requirements.txt
├── src/
│   ├── csv_agent.py     # Agent creation, system prompt and query building
│   ├── chat_loop.py     # Terminal chat loop
│   └── loader.py        # Downloads the sample CSVs from Google Drive
├── data/                # Copies of the sample CSVs
└── *.csv                # Sample datasets (SaaS docs, credit card terms, hospital policy, e-commerce FAQs)
```

## Setup

Requires Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

## Run the Streamlit UI

```bash
streamlit run streamlit_app.py
```

The UI shows one step at a time:

1. **Add CSV files.** Upload one or more CSVs, or press *Load sample datasets* to download the bundled samples. Loaded files are listed with row and column counts and can be removed. *Next* is enabled once at least one file is loaded.
2. **OpenAI API key.** Enter your key in the masked field, then press *Start chat*. The key is kept only in the session and is not written to disk.
3. **Chat.** Ask questions about your data. *Back to settings* returns to step 2 and clears the chat. Changing the files or the key also clears the chat.

## Run the terminal version

```bash
python app.py
```

It downloads the sample CSVs if they are missing, prompts for the API key (hidden input), then starts a chat. Type `exit`, `quit` or `q` to stop.

## Configuration

Set in [src/csv_agent.py](src/csv_agent.py):

| Setting | Value |
|---|---|
| `MODEL_NAME` | `openai/gpt-6-luna` |
| `BASE_URL` | `https://openrouter.ai/api/v1` |

The base URL points at OpenRouter, so the key must be accepted by that endpoint. A standard OpenAI key (`sk-...`) will probably be rejected there. To use OpenAI directly, remove `base_url` from `create_agent` and set a model name OpenAI offers.

## How it works

1. Each CSV is read into a pandas DataFrame.
2. `build_system_prompt` lists the loaded file names and columns and sets the rules above (answer only from the data, ask when unclear).
3. `create_agent` builds a LangChain pandas DataFrame agent over all the DataFrames.
4. For each question, `build_query` joins the system prompt, the last 10 turns of conversation and the new question, and sends it to the agent.

## Security note

The pandas agent runs Python code generated by the model (`allow_dangerous_code=True`). That is acceptable for local use with data you trust. Do not expose the app publicly or run it on untrusted CSVs without sandboxing.
